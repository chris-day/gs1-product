About the product records

Version 1.2.1 · 4 October 2026. Four named GTINs are presented as human-readable product records with Schema.org Product JSON-LD in a script section.

Product names, identifiers, image sources and researched attributes retain their provenance. Merchant SKUs, publisher URLs and all offer fields are test fixtures.

Dal Giardino is a fictional GS1 demonstration brand. The frozen-cheese classification conflicts with the risotto demonstration identity and is omitted. The Tesco Raspberry Jam identity remains provisional.

The attached example informed the visual layout. No verifiable credentials, cryptographic proofs or reviews were copied from it. Ingredient and allergen statements are labelled as sourced examples or TEST ONLY humorous inventions, with exact-GTIN limitations. Credentials can be added later.

Images remain on external source hosts. Source addresses are listed as text on local source pages, while every HTML navigation link resolves within the Zensical site.
